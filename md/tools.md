# Tools

## Acciones disponibles por categoría

### 🖥️ Sistema
- Abrir/cerrar aplicaciones: Chrome, Brave, Discord, Spotify, VS Code, etc.
- Control de volumen: subir, bajar, silenciar, nivel exacto (0-100)
- Capturas de pantalla
- Bloquear/suspender PC

### 🎵 Multimedia
- YouTube: abrir, buscar, cerrar
- Spotify: abrir, cerrar
- VLC: abrir con archivo
- Controles: play/pause, siguiente, anterior

### 📁 Archivos
- Buscar archivos por nombre en el sistema
- Mover/copiar a Google Drive Sync
- Abrir archivos con app predeterminada
- Crear carpetas

### 💻 Terminal
- Ejecutar comandos de terminal
- Instalar paquetes (npm, pip)
- Crear y ejecutar scripts (.py, .sh, .bat)

### 🌐 Web
- Búsqueda web real (DuckDuckGo)
- Resultados con fuentes y URLs

### 🤖 Dispositivos Android
- Control via ADB: YouTube, volumen, screenshot, navegación

### 📊 Artifacts
- Diagramas Mermaid (flowchart, sequence, ER)
- Interfaces HTML
- Ilustraciones SVG
- Scripts ejecutables
